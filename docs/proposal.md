# Project Proposal: Scan2Study

## 1. Project Topic

Scan2Study transforms learning materials into organized study resources.
Users can capture materials using a camera or upload images and PDF files.

## 2. Target Users and Problem

Target users:
- University students
- High school students
- Independent learners

Students spend considerable time reviewing long documents and manually
creating summaries and flashcards.

Scan2Study aims to automate this process.

## 3. Input, Processing, and Output

### Input
- Camera-captured images
- Uploaded images
- PDF documents

### Processing
1. Receive an image or PDF.
2. Extract readable text using OCR or PDF text extraction.
3. Clean and organize the text.
4. Generate summaries.
5. Generate flashcards.

### Output
- Extracted text
- Organized summaries
- Question-and-answer flashcards

## 4. Scope

### In Scope
- Camera-based image capture
- Image and PDF uploads
- Text extraction
- Text cleaning
- Summary generation
- Flashcard generation

### Out of Scope
- Real-time classroom recording
- Advanced handwriting recognition
- Complex mathematical equation recognition
- Personalized learning recommendations

## 5. Usage Example

A student uploads a PDF containing lecture notes.
Scan2Study extracts the text, organizes important information,
generates a summary, and creates flashcards for revision.

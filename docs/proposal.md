# 프로젝트 제안서(Project proposal) · 형광펜 복습 자료 생성기

## 1. 프로젝트 주제(Project topic)

### 만들고 싶은 프로그램(What we want to build)

필기나 유인물 사진의 밝기와 대비를 보정하고, 노란 형광펜으로 표시한 부분을 한 장의 복습용 이미지로 모아주는 프로그램을 개발한다. 프로그램은 보정한 전체 문서와 복습용 이미지를 각각 저장한다.

### 사용자 정의 및 해결할 문제(Users and problem)

주요 사용자는 강의 필기나 유인물에 형광펜으로 표시해 두고 시험 전에 다시 보는 학생이다. 휴대전화로 찍은 사진은 조명에 따라 글씨가 어둡게 보일 수 있고, 표시가 여러 곳에 흩어져 있으면 복습할 때마다 해당 부분을 다시 찾아야 한다. 이 프로그램은 필기 사진을 읽기 쉽게 보정하고 표시한 부분을 원래 순서대로 모아, 학생이 복습 자료를 따로 편집하는 수고를 줄인다.

## 2. 개발할 기능(Planned features)

### 입력(Input)

노란 형광펜 표시가 있는 강의 필기나 유인물의 컬러 사진 한 장을 입력받는다. 지원 형식은 JPG와 PNG다.

### 처리(Processing)

1. 입력한 컬러 사진을 불러온다.
2. 원본 사진에서 노란 형광펜의 색상 범위에 해당하는 픽셀을 찾는다.
3. 가까이 모인 픽셀을 하나의 표시 영역으로 묶고, 각 영역의 위치와 크기를 구한다.
4. 사진의 밝기와 대비를 조절해 글씨를 읽기 쉽게 보정한다.
5. 원본에서 찾은 영역의 좌표를 이용해 보정한 사진에서 표시 부분을 잘라낸다. 글씨가 잘리지 않도록 영역 주변에 여백을 둔다.
6. 잘라낸 부분을 위에서 아래로 배치한다. 같은 줄에 표시가 여러 개 있으면 왼쪽에서 오른쪽 순서로 정렬한다.
7. 보정한 전체 문서와 표시 부분을 모은 복습용 이미지를 각각 PNG 파일로 저장한다.

### 결과(Output)

- **보정된 전체 문서 이미지** · 원래 글씨와 페이지 배치를 유지하며, 밝기와 대비를 조절한 PNG 이미지다.
- **복습용 이미지** · 형광펜으로 표시한 부분을 글씨와 주변 여백까지 포함해 원본의 읽는 순서대로 모은 PNG 이미지다.

### 개발 범위(Scope)

- **포함 범위** · 사진 한 장의 밝기·대비 보정, 노란 형광펜 영역 탐지 및 추출, 복습용 이미지 생성과 저장
- **추가 기능 후보** · 형광펜 색상 선택, 원본과 복습 이미지에 같은 번호 표시, 빈칸 복습 모드, 문서 기울기 보정
- **첫 버전 제외 범위** · 여러 페이지 일괄 처리와 OCR을 통한 텍스트 변환
- **한계** · 그림자가 강하거나 형광펜 색이 흐리면 일부 표시를 놓칠 수 있다. 형광펜과 색이 비슷한 노란색 그림이나 인쇄 요소를 표시 영역으로 감지할 수도 있다.

### 사용 예시(Usage example)

시험을 준비하는 학생이 핵심 개념 세 곳에 노란 형광펜을 친 유인물 사진 `lecture_notes.jpg`를 입력한다. 프로그램은 전체 문서를 밝고 읽기 쉽게 보정한 `enhanced_notes.png`와 표시한 세 부분을 원래 순서대로 모은 `study_sheet.png`를 생성한다. 학생은 시험 직전에 복습용 이미지로 핵심 내용을 훑어보고, 앞뒤 설명이 필요할 때는 보정한 전체 문서를 확인한다.roject topic)

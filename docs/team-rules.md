# Team Rules

## Branch Naming
Use feature/feature-name for feature branches.

## Commit Messages
Use descriptive prefixes:
- feat: new features
- fix: bug fixes
- docs: documentation changes

## Pull Requests
- Keep changes focused.
- Explain what changed and why.
- Request at least two reviewers.
- Address review comments before merging.

## Merge Rules
Merge into main only after the required approvals.

## AI Usage Disclosure
Disclose AI tools used, where they were used,
what they contributed, and how the results were verified.
